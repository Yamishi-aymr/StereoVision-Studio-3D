# StereoVision Studio 3D

Aplicación web para visualizar y manipular imágenes y videos estereoscópicos mediante diferentes modos de visualización, incluyendo SBS (Side-by-Side), anaglifo y realidad virtual con Google Cardboard.

## Descripción

StereoVision Studio 3D es una herramienta web diseñada para facilitar la visualización de contenido 3D estereoscópico. Permite importar archivos multimedia, ajustar su visualización y utilizar dispositivos móviles con gafas VR para disfrutar de una experiencia inmersiva.

## Funcionalidades principales

### 1. Módulo Anaglifo

- Visualización de contenido mediante efecto anaglifo.
- Ajustes de visualización y calibración.
- Compatibilidad con imágenes y videos según el módulo.

### 2. Módulo Imagen SBS

- Importación de imágenes SBS.
- Ajuste de zoom y posición.
- Desplazamiento táctil mediante arrastre.
- Zoom mediante gesto de pellizco.
- Ajustes de alineación estereoscópica.
- Intercambio de perspectivas izquierda y derecha.

### 3. Módulo Video SBS

- Reproducción de videos estereoscópicos.
- Controles de reproducción y pausa.
- Barra de progreso y control de volumen.
- Ajustes de zoom y posición.
- Manipulación mediante gestos táctiles.
- Sincronización de ambas perspectivas.

### 4. Modo VR

- Visualización estereoscópica en pantalla dividida.
- Compatibilidad con Google Cardboard.
- Controles flotantes de reproducción.
- Reproducción automática y modo bucle para videos.
- Controles de pausa y reanudación.
- Salida del modo VR.

### 5. Configuración y calibración

- Configuración de referencia de distancia entre lentes.
- Guardado de preferencias en el navegador.
- Restablecimiento de ajustes de visualización.
- Manipulación de contenido mediante pantalla táctil.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES Modules)
- Canvas API
- HTML5 Video API
- Pointer Events API
- LocalStorage API

## Requisitos

- Navegador web moderno.
- Conexión a internet para acceder a la versión publicada.
- Teléfono inteligente para probar los gestos táctiles.
- Google Cardboard o visor VR compatible para la experiencia inmersiva.

## Uso de la aplicación

1. Ingresar a StereoVision Studio 3D.
2. Seleccionar uno de los tres módulos disponibles.
3. Importar una imagen o video compatible.
4. Realizar los ajustes de visualización necesarios.
5. Utilizar los controles táctiles o deslizadores para manipular el contenido.
6. Activar el modo VR para utilizar Google Cardboard cuando corresponda.
